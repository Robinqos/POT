# Laboratórne cvičenie 2

Základy jazyka C# a .NET

Celý ZIP rozbaľte. Vo Visual Studiu 2026 otvorte starter/SmartLogistics.slnx.
Projekty používajú .NET 10. Vyžadujú .NET 10 SDK a prvé obnovenie balíkov cez NuGet.
Návod POT_Lab02_Navod.docx si stiahnite zo stránky cvičenia v Moodle.

Pracujte vlastným tempom. Riešenie sa neodovzdáva.
Môžete používať GitHub Copilot, internet a Antigravity.

Príkazy spúšťajte z priečinka starter:

    dotnet restore SmartLogistics.slnx
    dotnet build SmartLogistics.slnx
    dotnet test SmartLogistics.slnx
    dotnet run --project SmartLogistics.App

Na začiatku prejde 11 zo 40 testovacích prípadov. Ostatné čakajú na doplnenie TODO.
